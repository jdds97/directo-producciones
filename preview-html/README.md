# Presentación M4 → Astro

Abrir index.html en un navegador. Incluye todas las páginas de diseño, temas claro/oscuro, navegación, menú responsive, guía visual y plantillas. Los HTML se exportan del Worker Astro verificado; el blog es una instantánea sintética. Copy M4 en borrador, legales pendientes y formulario deshabilitado. No es un despliegue de producción. EmDash se demuestra mediante el Worker local, no mediante estos HTML.

Regenerar con el Worker local activo: npm run export:presentation.
